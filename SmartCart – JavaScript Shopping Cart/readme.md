# 🛒 Shopping Cart

A simple and responsive **Shopping Cart** web application built using **HTML**, **CSS**, and **Vanilla JavaScript**. Users can browse products, add them to the cart, view the total price, and complete the checkout process. This project demonstrates fundamental JavaScript concepts such as DOM manipulation, event handling, arrays, and dynamic UI updates.

---

## 📌 Features

- Display a list of available products
- Add products to the shopping cart
- Dynamic cart updates
- Real-time total price calculation
- Empty cart message when no items are added
- Checkout functionality
- Clean and responsive user interface
- Beginner-friendly implementation

## 💡 How It Works

1. Products are stored in a JavaScript array.
2. The product list is rendered dynamically on page load.
3. Clicking **Add to Cart** adds the selected product to the cart.
4. The cart updates automatically with:
   - Added products
   - Running total price
5. Clicking **Checkout**:
   - Clears the cart
   - Displays a success message
   - Resets the total price
