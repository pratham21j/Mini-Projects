# 🧠 Interactive Quiz Application

An interactive **Quiz Application** built using **HTML**, **CSS**, and **Vanilla JavaScript**. The application presents multiple-choice questions, evaluates user answers, keeps track of the score, and displays the final result. It is an excellent beginner-friendly project for learning DOM manipulation, event handling, and application state management in JavaScript.

---

## 📌 Features

- Start quiz with a single click
- Multiple-choice questions
- Instant answer selection
- Score tracking
- Next question navigation
- Final score display
- Restart quiz functionality
- Clean and responsive interface
- Beginner-friendly implementation

## 🎮 How to Use

1. Click the **Start Quiz** button.
2. Read the displayed question carefully.
3. Select the correct answer from the available choices.
4. Click **Next** to move to the next question.
5. After answering all questions, your final score will be displayed.
6. Click **Restart Quiz** to play again.

---

## ⚙️ How It Works

- Questions are stored in a JavaScript array of objects.
- Each object contains:
  - Question
  - Multiple choices
  - Correct answer
- Questions are rendered dynamically.
- User selections are compared with the correct answer.
- The score is updated for each correct response.
- At the end of the quiz, the total score is displayed.
