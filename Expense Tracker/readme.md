# 💰 Expense Tracker

A simple and responsive **Expense Tracker** built with **HTML, CSS, and JavaScript** that allows users to add, view, and delete expenses while automatically calculating the total spending. All expense data is stored in the browser using **Local Storage**, ensuring persistence even after refreshing or reopening the page.

---

## 📌 Features

- ➕ Add new expenses with name and amount
- 🗑️ Delete expenses instantly
- 💵 Automatically calculate total expenses
- 💾 Data persistence using Local Storage
- ⚡ Real-time UI updates
- 📱 Responsive and user-friendly interface
- 🚫 Input validation to prevent invalid entries

---

## 📸 Application Workflow

1. Enter the expense name.
2. Enter the expense amount.
3. Click **Add Expense**.
4. The expense is displayed in the list.
5. The total amount updates automatically.
6. Click **Delete** to remove an expense.
7. All data is saved in Local Storage.

## 🔍 How It Works

- Expenses are stored as objects containing:
  - Unique ID
  - Expense Name
  - Expense Amount
- Every addition or deletion updates:
  - Expense list
  - Total amount
  - Local Storage
- On page reload, saved expenses are automatically loaded from Local Storage.
