# Mini Projects

A collection of beginner-friendly JavaScript mini projects demonstrating DOM manipulation, API usage, and interactive web app functionality.

## Projects

- **Expense Tracker**
  - Track incomes and expenses.
  - Uses JavaScript to add, remove, and display transaction data.

- **Live Weather App**
  - Fetches weather information for a city.
  - Demonstrates API requests and dynamic UI updates.

- **Quiz App**
  - Interactive quiz with multiple-choice questions.
  - Shows score calculation and question navigation.

- **SmartCart – JavaScript Shopping Cart**
  - Shopping cart interface with product selection.
  - Includes cart management and item quantity updates.

- **Todo App**
  - Simple task management tool.
  - Allows adding, completing, and removing todos.

## How to Use

1. Open the desired project folder.
2. Open `index.html` in a browser.
3. Interact with the app and review the JavaScript behavior in `script.js`.
4. Customize styles in `styles.css` as needed.

## Notes

- Each app is self-contained in its own folder.
- No build tools or dependencies are required.
- Ideal for learning and experimenting with vanilla JavaScript.
